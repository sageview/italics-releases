# Italics releases

Download and update artifacts for **Italics**, a WYSIWYG Markdown editor for Windows and Mac.

## Get Italics

Learn more at **[useitalics.com](https://useitalics.com)**.

Download the free trial directly at **[useitalics.com/download](https://useitalics.com/download)**.

## What's in this repo

Release artifacts only. Every release carries these:

| Asset                                          | Purpose                                                      |
|------------------------------------------------|--------------------------------------------------------------|
| `Italics-setup.exe`                            | The Windows installer, at a permanent URL that never changes |
| `Italics_<version>_x64-setup.exe`              | The same installer, version-stamped                          |
| `Italics_<version>_x64-setup.exe.sig`          | minisign signature, verified by the in-app updater           |
| `Italics.dmg`                                  | The Mac disk image, at a permanent URL that never changes    |
| `Italics_<version>_universal.dmg`              | The same disk image, version-stamped                         |
| `Italics_<version>_universal.app.tar.gz`       | The Mac update, downloaded by the in-app updater             |
| `Italics_<version>_universal.app.tar.gz.sig`   | minisign signature, verified by the in-app updater           |
| `latest.json`                                  | The update manifest the app checks                           |
